SCORING, EXPLAINED

分数之外，
还要看证据覆盖。Beyond the score,
check the evidence coverage.

此处解释现有「模型检测」的信号加权算法。各专项报告有自己的证据维度，不将所有检测强行归为同一分数。This explains the model-authenticity signal weighting. Specialized tests have their own evidence dimensions.

评分 = Σ(有效权重 × 信号分) / Σ有效权重 × 100
证据覆盖 = 有效权重 / 总权重Score = Σ(weight × signal) / Σvalid weight × 100
Coverage = valid weight / total weight

跳过或不可用的信号不进入分母；无有效证据时返回零分与零覆盖。高分不等于绝对真实。Skipped or unavailable signals are excluded. No usable evidence yields zero score and coverage. A high score is not a guarantee.

A LITTLE MORE CONTEXT

开始之前，你可能想问A few things worth knowing.

需要注册账号吗？Do I need an account?

无需注册。选择检测类型后，在对应检测页面填写信息即可。No registration. Choose a test and enter the required details on its page.

API Key 会被保存吗？Is my API key stored?

产品设计为 Key 不留存。本静态原型不收集 Key，也不发起真实检测；正式使用前可审计项目代码或选择自托管。The product is designed not to retain keys. This prototype collects no keys and runs no real tests. Audit the code or self-host before use.

高分等于绝对真实吗？Does a high score guarantee authenticity?

不等于。分数反映已获取的检测信号，应结合证据覆盖、协议特征和具体来源线索阅读。No. Scores reflect observed signals. Read them alongside evidence coverage, protocol features and source clues.

检测会产生 API 费用吗？Can detection incur API costs?

工具免费，真实检测可能向你的服务商发送请求，服务商可能按其规则计费。此原型不会发送请求。The tool is free; real tests may make provider requests billed under their terms. This prototype sends none.

可以完全自托管吗？Can I self-host?

可以。项目支持自托管；部署方式和环境要求请查看 GitHub 项目说明。Yes. See the GitHub repository for deployment instructions and requirements.
